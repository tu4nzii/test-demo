# Chart Demo UI

Vue 3 + Vite frontend for the chart analysis demo.

## Development

```powershell
cd F:\program\test-demo\frontend\chart-demo-ui
npm.cmd install
npm.cmd run dev
```

Default URL:

```text
http://127.0.0.1:5173
```

Backend default:

```text
http://127.0.0.1:8000
```

Override the backend URL with `VITE_API_URL` if needed.

## Features

- Custom image upload.
- Dataset preview by source and category.
- Standard gray encrypted-grid view.
- Colored grid preview for visual inspection.
- Evaluation prediction result view.
- Processed JSON/result detail view.

## Dataset Preview

The UI first loads categories, then lazily loads samples for the selected category. This avoids loading the full dataset at startup.

Supported sources:

- `Final-RealDataset`
- `Sy.Dataset`

Preview cache is generated by the backend. Custom upload does not use this cache.

## Build

```powershell
npm.cmd run build
```

## Notes

- If PowerShell blocks `npm.ps1`, use `npm.cmd`.
- The UI expects backend responses to include `standard_grid_url` for the formal gray result and may include `colored_grid_url` for preview.
- Evaluation prediction results are fetched through `/api/results/{filename}` and normalized by the backend.
