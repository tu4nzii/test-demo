# 简短审稿回复：参数与可复现性

## Comment 1.7

**审稿意见：** Gaussian filter 和 Canny edge detection 的参数是如何选择的？这些参数是否对所有图像固定？性能对这些参数是否敏感？

**回复：** 各类图表内部使用固定参数，不针对单张图像调参。Gaussian smoothing 只用于局部 OCR 文本处理或圆形/径向检测，其中 OCR 裁剪使用 `(3,3), sigma=0`，圆形/径向检测使用 `(9,9), sigma=2`。

参数敏感性通过边界明确的 edge/circle 参数诊断说明。中等范围内的 Canny 阈值变化对线候选数量影响较小，而 Hough threshold 对候选数量影响更明显。Radar/rose 在 99 张 polar 样本上扫描 Hough `param2`，结果显示 `param2=30` 保持 100% 圆检测返回率，同时相比更宽松阈值减少平均候选圆数量。完整评估中，直角坐标系图表的 Tick MAE 为 `0.691 px`，Tick Acc@2px 为 `96.37%`，标签准确率为 `96.13%`，图表类型分类准确率为 `100.00%`；极坐标图表类型分类准确率为 `96.64%`。该分类指标中，`bubble` 与 `scatter` 按点图族互认。

## Comment 2.6[2]

**审稿意见：** 部分技术细节仍然描述不足。影响可复现性的关键实现细节没有充分说明，包括图表类型分类的鲁棒性、轴线/tick 提取参数设置，以及 zoom-in verification 机制的具体实现。

**回复：** 图表类型分类由 MLLM JSON 提取器完成，调用温度为 `temperature=0`。输出类型必须属于支持的类型注册表，如果类型缺失或不受支持，系统显式报错。图表分类准确率中，`bubble` 与 `scatter` 按点图族互认。最新全量评估中的图表类型分类准确率为：整体 `98.95%`，直角坐标系 `100.00%`，极坐标系 `96.64%`。

网格和 tick 提取参数对所有图像固定，不针对单张图像调整。我们补充说明了审稿意见中涉及的关键设置，包括图像阈值、形态学处理、线段聚类、OCR 阈值、圆形/径向结构检测和 `tick_density` 的固定使用方式；径向 tick 数值由 MLLM 从图像中读取。

Zoom-in verification 用于数值预测阶段。该机制在局部裁剪中验证目标可见性，再接受或重试预测；pie/donut 通过三轮裁剪放大细化扇区估计，radar/rose 则同时使用生成后的网格图、原图和检测到的 tick 信息。
