# 简短审稿回复：参数与可复现性

## Comment 1.7

**审稿意见：** Gaussian filter 和 Canny edge detection 的参数是如何选择的？这些参数是否对所有图像固定？性能对这些参数是否敏感？

**回复：** 各类图表内部使用固定参数，不针对单张图像调参。系统会根据图表几何使用不同视觉证据：直角坐标系网格来自低饱和度灰色像素、局部对比度和形态学横/竖线过滤，并结合 OCR/MLLM 证据选择最终网格候选；pie/donut 主要通过颜色 mask 和连通域证据定位圆形绘图区；radar/rose 使用径向圆环证据。Gaussian smoothing 因此只用于局部 OCR 文本处理或圆形/径向检测，其中 OCR 裁剪使用 `(3,3), sigma=0`，圆形/径向检测使用 `(9,9), sigma=2`。Canny edge detection 不属于当前直角坐标系网格重建流程。

参数敏感性通过边界明确的 edge/circle 参数诊断说明。中等范围内的 Canny 阈值变化对线候选数量影响较小，而 Hough threshold 对候选数量影响更明显。Radar/rose 在 99 张 polar 样本上扫描 Hough `param2`，结果显示 `param2=30` 保持 100% 圆检测返回率，同时相比更宽松阈值减少平均候选圆数量。完整评估中，直角坐标系图表的 Tick MAE 为 `0.691 px`，Tick Acc@2px 为 `96.37%`，标签准确率为 `96.13%`，图表类型分类准确率为 `100.00%`；极坐标图表类型分类准确率为 `96.64%`。该分类指标中，`bubble` 与 `scatter` 按点图族互认。

## Comment 2.6[2]

**审稿意见：** 部分技术细节仍然描述不足。影响可复现性的关键实现细节没有充分说明，包括图表类型分类的鲁棒性、轴线/tick 提取参数设置，以及 zoom-in verification 机制的具体实现。

**回复：** 图表类型分类由 MLLM JSON 提取器完成，调用温度为 `temperature=0`。输出类型必须属于支持的类型注册表：`rose`、`radar`、`v_bar`、`h_bar`、`line`、`scatter`、`bubble`、`donut` 或 `pie`。如果类型缺失或不受支持，系统显式报错，不回退到默认类别。图表分类准确率中，`bubble` 与 `scatter` 按点图族互认。最新全量评估中的图表类型分类准确率为：整体 `98.95%`，直角坐标系 `100.00%`，极坐标系 `96.64%`。

网格和 tick 提取参数对所有图像固定。这些固定设置覆盖饱和度、灰度、局部对比度、形态学、线段跨度、聚类、OCR 阈值、圆形绘图区检测、角度网格间隔、径向圆环检测和 `tick_density`。这些参数共同用于恢复直角坐标系横/竖网格候选、pie/donut 角度网格以及 radar/rose 径向 tick 结构；径向 tick 数值由 MLLM 从图像中读取。

Zoom-in verification 用于数值预测阶段，而不是网格重建阶段。柱状图、散点图和气泡图围绕预测目标裁剪，并验证目标是否可见；不可见时重试。折线图围绕目标 x 类别和当前 y 估计裁剪。Radar/rose 同时使用生成后的网格图和原图，并结合检测到的径向与角度 tick 信息。Pie/donut 通过三轮裁剪放大细化扇区估计，并由 MLLM 检查扇区可见性和角度顺序。
