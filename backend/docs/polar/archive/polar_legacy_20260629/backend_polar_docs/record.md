## 1. 圆形雷达图区域裁剪

### 1.1 主要目标

原始图片可能包含大量空白区域、角落图标和无关文字。直接在整图上检测会导致圆的半径范围难以确定，并增加误检概率。

### 1.2 安全裁剪流程

- 将图像中的非白色像素作为前景，通过形态学闭运算连接分散的网格线、数据区域和文字。
- 选择面积最大的连通区域作为主要图表区域，排除角落图标和大块空白区域的影响。
- 在主要图表区域外增加安全边距，并生成正方形 ROI，保证圆形网格不会被裁剪或拉伸。
- 将 ROI 等比例缩放并补白到 `800×800`，仅用于圆检测。
- 保存裁剪偏移、缩放比例和补白偏移，将检测出的圆心和半径映射回原图坐标。
- 裁剪区域不完整、候选圆靠近边界或检测失败时，自动回退到整图检测。
- 原图不会被修改，后续加密和标注继续使用原图坐标与尺寸。

## 2. 圆形雷达图霍夫圆参数算法

### 2.1 基础参数

- `dp=1.0`：累加器分辨率与输入图像接近，保留较高的圆心定位精度。
- `minDist=12`：允许生成多个相近候选圆，之后再统一评分。
- `param1=50`：霍夫圆内部 Canny 边缘检测的高阈值。
- 首圆半径范围根据标准化后的 `800×800` 检测图动态确定。
- 第二圆分别搜索比首圆更大或更小的近似同心圆。

### 2.2 多 `param2` 阈值搜索

`param2` 是霍夫圆累加器阈值，表示候选圆需要获得的边缘投票数量：

- `param2` 越大，要求圆周越清晰、完整，候选数量越少。
- `param2` 越小，越容易检测浅灰色、断裂或被数据区域遮挡的圆，但也会产生更多误检。

当前策略：

- 首圆依次尝试 `30、25、20、15`。
- 第二圆优先尝试 `50、25、20、15`。
- 不同阈值产生的圆统一加入候选集合，并去除重复候选。
- 最终不会直接采用某个阈值返回的第一个圆，而是统一经过安全检查和候选评分。

因此，多阈值搜索同时缓解了单一高阈值容易漏检、单一低阈值容易误检的问题。

### 2.3 候选圆安全检查

- 候选圆必须完整位于裁剪 ROI 和原图范围内。
- 候选圆不能过于靠近裁剪边界。
- 第二圆必须与第一圆近似同心。
- 与第一圆半径近似重复的候选圆会被丢弃。
- 检测失败时自动使用整图回退。

### 2.4 圆周边缘覆盖率

圆周边缘覆盖率用于判断候选圆与真实网格圆的重合程度：

1. 在圆周上均匀采样 `180` 个角度。
2. 每个角度检查 `r-2、r-1、r、r+1、r+2` 五个半径位置。
3. 只要其中存在 Canny 边缘，就认为该角度获得边缘支持。

公式：

```text
edge_support = 获得边缘支持的角度数量 / 180
```

覆盖率越高，说明候选圆与真实网格圆重合得越完整。

### 2.5 圆心约束与候选评分

- 圆心不一定位于整张图片中心，因此不会强制候选圆靠近画布中心。
- 根据主要图表区域估计内容中心，只作为低权重软先验。
- 当多个不同半径候选具有相近圆心，增加少量同心候选一致性得分。
- 如果检测到可靠的灰色圆盘中心，则对候选圆心进行更严格约束。
- 第二圆使用其圆心与第一圆圆心的距离进行同心约束。

最终评分综合：

```text
圆周边缘覆盖率
+ 同心候选一致性
- 低权重内容中心偏差
```

### 2.6 刻度与半径关系

两个可靠圆及其刻度值保持成对关系，通过两个点拟合：

```text
radius = a × tick + b
```

无法可靠识别第二圆时，自动使用单圆流程。

## 3. 圆形雷达图灰度增强

- 在霍夫圆检测前使用 CLAHE 对灰度图进行局部对比度增强，使浅灰色网格线更加清晰。
- 增强图经过高斯平滑后再进行霍夫圆检测，降低噪声和文字边缘产生的干扰。
- 灰度增强只用于检测输入，不修改原始图像，也不影响最终输出图的颜色和尺寸。
- 对包含大面积中性灰色圆盘的图表，可以利用圆盘区域提供可靠圆心先验，减少彩色数据区域造成的圆心偏移。

## 4. 多边形雷达图网格加密

### 4.1 总体流程

多边形雷达图采用双通道几何检测：

1. 优先使用闭合轮廓与 `approxPolyDP` 检测外层多边形。
2. 闭合轮廓失败时，使用径向轴线、交点聚类和等角约束进行回退检测。
3. 根据正多边形约束优化圆心并修正异常顶点。
4. 搜索真实多边形网格层并识别对应 tick。
5. 拟合 tick 与半径关系。
6. 插入虚线多边形网格，并在上、右、下、左四个位置标注新增刻度值。

### 4.2 闭合轮廓检测

首先对灰度图依次尝试多个二值化阈值：

```text
180、200、220、235、245
```

使用 `findContours` 提取闭合轮廓，再通过 `approxPolyDP` 简化为多边形顶点。

候选多边形必须满足：

- 顶点数量为 `5～24`。
- 必须是凸多边形。
- 面积不能过小。
- 各边长度需要接近。
- 各顶点到圆心的距离需要接近。

候选评分：

```text
score = 面积占比 × 100
        - 半径变异系数 × 120
        - 边长变异系数 × 80
```

成功时记录：

```text
detection_source = closed_contour
```

### 4.3 径向轴线回退检测

浅色、断裂或被数据区域覆盖的外框可能无法形成完整闭合轮廓。此时使用径向轴线回退：

1. 使用 CLAHE 增强浅色轴线。
2. 使用 Canny 提取边缘。
3. 使用 `HoughLinesP` 检测较长直线。
4. 计算直线之间的交点，并对交点进行空间聚类。
5. 将多条轴线集中经过的位置作为候选圆心。
6. 依次尝试 `5～20` 边模型，并检查轴线方向是否接近等角分布。

对于边数 `n`：

```text
理论相邻轴线角度 = 360° / n
```

当前要求至少约 `75%` 的理论轴线方向获得真实直线支持，否则拒绝结果。

随后围绕候选圆心生成不同半径的正多边形，根据边缘覆盖率选择可靠的最外层半径。

成功时记录：

```text
detection_source = radial_axes_fallback
```

### 4.4 初始圆心计算

检测到多边形顶点后，先按照顶点相对于中心的方向角排序。

偶数边多边形使用相对顶点中点：

```text
顶点 0 ↔ 顶点 n/2
顶点 1 ↔ 顶点 n/2+1
```

计算所有相对顶点中点，再取中位数作为初始圆心。

奇数边多边形使用所有顶点的平均坐标作为初始圆心。

### 4.5 正多边形圆心优化

在初始圆心附近搜索更合适的圆心，评分同时考虑：

- 相邻顶点夹角是否接近 `360° / n`。
- 各顶点到圆心的半径是否一致。

一个异常顶点会影响两个相邻夹角，因此评分时允许忽略：

- 最大的两个角度误差。
- 最大的一个半径误差。

如果初始多边形已经非常规则，则保持原圆心不变。

### 4.6 异常顶点修正

检测顶点只作为观测结果，最终顶点根据正多边形模型重新生成：

```text
vertex_i = center + radius ×
           (cos(phase + i × 360°/n),
            sin(phase + i × 360°/n))
```

这样可以保证：

- 所有顶点位于同一个圆周上。
- 所有相邻顶点夹角严格相等。
- 异常偏移顶点会被其他可靠顶点推断的位置替换。

JSON 中保存：

- `detected_vertices`：原始检测顶点。
- `vertices`：正多边形修正后的顶点。
- `corrected_vertex_indices`：异常顶点编号。
- `vertex_correction_distances`：各顶点修正距离。
- `max_final_angle_error_degrees`：最终最大角度误差。

### 4.7 网格层检测

使用 CLAHE、GaussianBlur 和 Canny 提取网格边缘。

从外框的 `0.10～1.01` 比例逐步生成缩放多边形：

```text
0.10、0.11、0.12 ... 1.00
```

对于每个缩放多边形：

- 在每条边上均匀采样。
- 检查采样点附近 `5×5` 像素区域是否存在边缘。
- 计算多边形边缘覆盖率。

随后：

- 合并粗线产生的相邻重复峰值。
- 优先选择外层可靠网格。
- 网格层之间至少间隔约 `0.18`。
- 最多选择三个网格层。

### 4.8 为什么最多识别三个 tick

拟合线性关系理论上只需要两个可靠 tick：

```text
radius = a × tick + b
```

第三个 tick 用于容错：

- 某一个 tick 误识别时，仍可以从其他两个建立关系。
- 验证刻度是否随半径增大。
- 选择跨度更大、截距更合理的刻度组合。
- 计算真实最小刻度间隔。

因此，算法最多寻找三个 tick，但不强制必须识别三个。

### 4.9 tick 与半径关系校验

遍历所有有效 tick 配对，仅保留满足以下条件的关系：

```text
tick 越大，半径越大
a > 0
abs(b) <= 最大半径 × 20%
```

截距限制用于拒绝明显错误的 tick，例如把图例数字误认为刻度值。

### 4.10 网格加密与四方向刻度标注

根据识别出的刻度间隔和加密密度插入中间刻度。

例如：

```text
原始刻度间隔 = 20
加密密度 = 2
新增刻度间隔 = 10
```

通过关系式计算新增刻度对应半径：

```text
radius = a × tick + b
scale = radius / outer_radius
```

随后绘制对应的虚线正多边形网格。

每条新增虚线网格会在以下四个位置标注刻度值：

```text
顶部、右侧、底部、左侧
```

多边形标注不会直接使用圆形半径位置，而是计算中心射线与当前多边形边界的真实交点，因此旋转后的多边形也能正确放置文字。

文字处理包括：

- 根据图像尺寸和网格间距自动缩放字号。
- 使用黑色文字与白色描边，避免文字被数据区域或网格线遮挡。
- 只标注新增的加密层，不重复标注原图已有主刻度。

### 4.11 输出状态

批处理使用三种状态：

#### `success`

几何检测、tick 关系和网格加密全部可靠。

#### `partial_geometry_only`

圆心和多边形几何可用，但网格层或 tick 关系不可靠。输出的加密图仅为等分预览，不能视为可靠刻度加密结果。

#### `geometry_failed`

没有获得足够可靠的几何结果，算法安全拒绝，避免输出错误多边形。

## 5. Pie 图的圆心和半径寻找

Doughnut 图除了外圆之外还需要检测内圆，因此将在后续单独处理。

Pie 检测脚本：

```text
backend/demo_pie/demo_pie_circle_find_1.py
```

Pie 批处理脚本：

```text
backend/demo_pie/demo_pie_circle_batch.py
```

### 5.2 彩色主区域提取

Pie 图通常由高饱和度彩色扇区组成，而图例、标题和背景大多位于饼图区域之外。

首先将图像转换为 HSV 和灰度图，并提取满足以下条件的像素：

```text
饱和度 >= 35
灰度值 < 245
```

对彩色掩码执行形态学闭运算，连接扇区边界处的小间隙。

随后使用连通区域分析，选择面积最大的彩色连通区域作为主要 Pie 区域，从而排除右侧图例色块等较小区域。

### 5.3 安全 ROI 与标准化

根据主要彩色区域生成正方形 ROI：

- ROI 边长约为主要彩色区域最长边的 `1.35` 倍。
- ROI 边界限制在原图范围内。
- ROI 缩放到固定 `800×800` 检测图。
- 保存 ROI 偏移和缩放比例，用于将检测结果映射回原图。

扩大 ROI 可以避免爆炸饼图中向外移动的扇区被裁掉。

### 5.4 灰度增强与多阈值霍夫圆检测

在标准化检测图上执行：

1. 转换为灰度图。
2. 使用 CLAHE 增强局部对比度。
3. 使用高斯平滑降低文字和像素噪声干扰。
4. 使用霍夫圆检测生成外圆候选。

霍夫圆使用多个累加器阈值：

```text
param2 = 50、35、25、20、15
```

高阈值负责寻找清晰完整的外圆，低阈值用于补充浅色、断裂或爆炸饼图的外圆。

检测半径范围基于标准化图确定：

```text
最小半径约为检测图短边的 30%
最大半径约为检测图短边的 53%
```

### 5.5 彩色连通区域外接圆回退

当 Pie 外圆边缘不完整，或者霍夫圆候选不可靠时，使用最大彩色连通区域的最小外接圆作为回退候选：

```python
cv2.minEnclosingCircle()
```

这种方式适用于：

- 外圆边缘没有明确描边。
- 扇区颜色连续，整体彩色区域较完整。
- 霍夫圆难以获得足够边缘投票。

所有霍夫圆候选和外接圆候选会进入同一个候选评分流程。

### 5.6 圆周边缘覆盖率

对每个候选圆的圆周均匀采样 `360` 个角度。

每个角度检查：

```text
r-2、r-1、r、r+1、r+2
```

只要附近存在 Canny 边缘，就认为该角度获得边缘支持。

公式：

```text
edge_support = 获得边缘支持的角度数量 / 360
```

圆周边缘覆盖率越高，候选圆越可能与真实 Pie 外圆重合。

### 5.7 彩色扇区填充覆盖率

为了避免选择文字边缘或空白区域形成的错误圆，在候选圆半径约 `75%` 的位置采样彩色掩码。

公式：

```text
fill_support = 位于彩色扇区内的采样点数量 / 总采样点数量
```

候选评分主要由圆周边缘覆盖率决定，同时使用填充覆盖率作为辅助：

```text
score = edge_support × 140
        + fill_support × 20
        + 外接圆回退奖励
```

提高圆周覆盖率权重，可以避免误选位于 Pie 内部、填充完整但半径偏小的圆。

### 5.8 轻微边界裁切处理

部分 Pie 图的真实外圆可能贴近图像边界，甚至被裁掉少量像素。

如果强制要求候选圆完整位于图像内部，会错误丢弃这些真实圆。因此当前允许外圆存在最多约半径 `3%` 的轻微越界：

```text
clipping_tolerance = max(3 像素, radius × 3%)
```

该机制成功处理了底部轻微裁切的 `Piechart4`。

### 5.9 爆炸饼图处理

## 6. Doughnut 图的内外圆检测

### 6.1 核心问题

霍夫圆返回的候选顺序不代表内径或外径，因此不能直接将第一个圆作为外圆、第二个圆作为内圆。

Doughnut 图的内外边界具有明确的径向颜色结构：

```text
圆心区域：空白
内径之外：彩色圆环
外径之外：背景
```

因此当前算法不依赖霍夫圆返回顺序，而是根据圆周两侧的颜色跃迁区分内径和外径。

Doughnut 检测脚本：

```text
backend/demo_donut/demo_donut_circle_find_1.py
```

Doughnut 批处理脚本：

```text
backend/demo_donut/demo_donut_circle_batch.py
```

### 6.2 圆心候选来源

算法综合使用两类结构候选：

#### 中心白色孔洞

- 提取接近白色的区域。
- 排除与图像边界连接的背景区域。
- 选择面积足够大、宽高比例接近圆形的内部白色区域。
- 使用白色孔洞的最小外接圆提供圆心候选和内径提示。

中心白色孔洞通常比外圆更稳定，即使圆环颜色很浅或外边界不完整，孔洞仍可提供可靠圆心。

#### 彩色圆环外轮廓

- 根据 HSV 饱和度和灰度值提取彩色圆环掩码。
- 使用形态学闭运算连接较小的扇区间隙。
- 对面积较大的彩色轮廓计算最小外接圆，提供额外圆心候选。

所有圆心候选都会经过完整径向结构评分，不会直接采用。

### 6.3 径向颜色扫描

对于每个圆心候选，从较小半径向外逐像素扫描。

每个半径在圆周上均匀采样 `360` 个角度，并计算：

```text
occupancy(r) = 位于彩色圆环中的采样点数量 / 360
```

随后比较当前半径内外两侧的彩色覆盖率：

```text
inside  = occupancy(r - 3)
outside = occupancy(r + 3)
```

### 6.4 内径识别

内径的内侧应为空白，外侧应为彩色圆环：

```text
inner_transition = outside - inside
```

可靠内径应满足：

```text
inner_transition >= 0.35
outside >= 0.45
```

`inner_transition` 越大，说明该半径越符合：

```text
空白中心 → 彩色圆环
```

### 6.5 外径识别

外径的内侧应为彩色圆环，外侧应为背景：

```text
outer_transition = inside - outside
```

可靠外径应满足：

```text
outer_radius >= inner_radius × 1.15
outer_transition >= 0.35
inside >= 0.45
```

`outer_transition` 越大，说明该半径越符合：

```text
彩色圆环 → 外部背景
```

### 6.6 为什么能够区分霍夫圆的内外径

内径和外径并不是通过候选顺序区分，而是通过颜色变化方向区分：

| 边界 | 内侧状态 | 外侧状态 | 跃迁方向 |
|---|---|---|---|
| 内径 | 空白 | 彩色 | `outside - inside > 0` |
| 外径 | 彩色 | 背景 | `inside - outside > 0` |

两条边界必须使用同一个候选圆心，因此最终结果天然满足近似同心约束。

### 6.7 半径平台中位数

由于颜色跃迁会在连续几个半径位置上保持较高值，直接选择第一个最大值会导致：

- 内径系统性偏小。
- 外径系统性偏大。

当前算法会收集接近最大跃迁值的半径平台，并选择平台中位数作为最终半径。

该方法将内外半径误差降低到约 `0～1` 像素。

### 6.8 爆炸外环识别与跳过

普通 Doughnut 图在绝大多数角度上的最外彩色半径应接近同一个外径。

算法沿 `360` 个角度分别寻找最外彩色像素，并计算：

```text
outer_radius_consistency =
最外彩色半径接近候选外径的有效角度数量 / 有效角度总数
```

当前要求：

```text
outer_radius_consistency >= 0.85
```

如果扇区被向外移动，或者多个扇区不共享同一个外圆，最外彩色半径会产生明显波动，算法将其判断为爆炸外环并跳过。

当前暂时跳过：

```text
DonutChart11
DonutChart13
DonutChart14
```

### 6.9 最终安全条件

只有同时满足以下条件才输出结果：

```text
inner_transition >= 0.65
outer_transition >= 0.65
outer_radius_consistency >= 0.85
outer_radius >= inner_radius × 1.15
```

无法满足时安全跳过，不强行输出错误圆心或半径。
