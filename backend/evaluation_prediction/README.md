# Backend Evaluation Prediction

This package contains backend-local value prediction flows ported from
`prediction_core` for Cartesian chart variants:

- `v_bar`
- `h_bar`
- `line`
- `scatter`
- `bubble`

For backend integration, use the JSON generated by the encryption step:
`backend/data/output/<chart_type>/*_image.json`. The loader automatically merges
the sibling `*_image_ticks.json` file so prediction receives the encrypted grid
image, ticks, pixels, and colors from the current system run.
Generated prediction outputs are written under `backend/evaluation_prediction/results`.

Run examples:

```powershell
python -m backend.evaluation_prediction.run_chart v_bar --chart-ids v_bar_002 --batch-size 1
python -m backend.evaluation_prediction.run_chart h_bar --chart-ids h_bar_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart line --chart-ids line_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart scatter --chart-ids scatter_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart bubble --chart-ids bubble_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart v_bar --config-json backend\data\output\v_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart h_bar --config-json backend\data\output\h_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart line --config-json backend\data\output\line\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart scatter --config-json backend\data\output\scatter\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart bubble --config-json backend\data\output\bubble\<chart>_image.json --batch-size 1
```

Environment overrides:

- `EVALUATION_PREDICTION_RESULTS_ROOT`: output root, defaults to `backend/evaluation_prediction/results`
- `CHART_BASE_URL`, `CHART_MODEL_NAME`, `CHART_API_KEY`, `OPENAI_API_KEY`, `CHART_API_URLS`: model configuration
- `CHART_REPEAT_TIMES`: repeat count per prompt/image setting

The API path only uses backend-generated JSON and does not hydrate prediction
inputs from bundled sample configs under `backend/charts`.
