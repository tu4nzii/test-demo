# Backend Evaluation Prediction

This package contains backend-local value prediction flows used by the system's
"evaluation prediction" step. Runtime code is self-contained in the backend and
does not import from `reference/`.

Supported chart variants:

- `v_bar`
- `h_bar`
- `v_stacked_bar`
- `h_stacked_bar`
- `line`
- `scatter`
- `bubble`
- `pie`
- `donut`
- `radar`
- `rose`

For backend integration, use the JSON generated by the encryption step:
`backend/data/output/<chart_type>/*_image.json`. The loader automatically merges
the sibling `*_image_ticks.json` file so prediction receives the encrypted grid
image, ticks, pixels, and colors from the current system run. The API path does
not hydrate prediction inputs from bundled sample configs under `backend/charts`
and does not consume GT unless the admin/backdoor flow explicitly enables it.

Generated prediction outputs are written under `backend/evaluation_prediction/results`.

Run examples:

```powershell
python -m backend.evaluation_prediction.run_chart v_bar --chart-ids v_bar_002 --batch-size 1
python -m backend.evaluation_prediction.run_chart h_bar --chart-ids h_bar_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart v_stacked_bar --chart-ids v_stacked_bar_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart h_stacked_bar --chart-ids h_stacked_bar_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart line --chart-ids line_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart scatter --chart-ids scatter_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart bubble --chart-ids bubble_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart pie --chart-ids pie_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart donut --chart-ids donut_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart radar --chart-ids radar_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart rose --chart-ids rose_001 --batch-size 1
python -m backend.evaluation_prediction.run_chart v_bar --config-json backend\data\output\v_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart h_bar --config-json backend\data\output\h_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart v_stacked_bar --config-json backend\data\output\v_stacked_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart h_stacked_bar --config-json backend\data\output\h_stacked_bar\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart line --config-json backend\data\output\line\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart scatter --config-json backend\data\output\scatter\<chart>_image.json --batch-size 1
python -m backend.evaluation_prediction.run_chart bubble --config-json backend\data\output\bubble\<chart>_image.json --batch-size 1
```

Environment overrides:

- `EVALUATION_PREDICTION_ASSETS_ROOT`: optional standalone sample asset root, defaults to `backend/evaluation_prediction/assets`
- `EVALUATION_PREDICTION_RESULTS_ROOT`: output root, defaults to `backend/evaluation_prediction/results`
- `CHART_MODEL_PROFILE`: unified model profile; current default is `gemini`
- `CHART_BASE_URL`, `CHART_MODEL_NAME`, `CHART_API_KEY`, `OPENAI_API_KEY`, `CHART_API_URLS`: per-field model overrides
- `CHART_REPEAT_TIMES`: repeat count per prompt/image setting
- `CHART_BAR_AMPLIFIER_ROUNDS`: h/v bar amplifier refinement rounds

Model profiles are defined in `backend/evaluation_prediction/common/model_config.py`
and exposed through the compatibility imports `model_api_config.py` and
`backend/model_api_config.py`.
