# Backend Evaluation Prediction

This package contains backend-local value prediction flows used by step 3, "evaluation prediction".

The prediction step is independent from grid generation. It receives the JSON and image paths generated by the current system processing chain and should not hydrate inputs from dataset GT or reference configs during normal runtime.

## Supported Runtime Types

Current system registry:

- `v_bar`
- `h_bar`
- `line`
- `scatter`
- `bubble`
- `pie`
- `donut`
- `radar`
- `rose`

Some internal runner code can still normalize or reuse stacked-bar helpers, but `main` does not currently register `v_stacked_bar` or `h_stacked_bar` as frontend/runtime chart types.

## Backend Integration

Use system-generated JSON from:

```text
backend/data/output/<chart_type>/*_image.json
backend/data/output/<chart_type>/*_image_ticks.json
```

The loader merges the sibling tick sidecar so prediction receives:

- encrypted grid path
- original image path
- ticks and pixels
- encrypted ticks and pixels
- axis types
- colors / series colors

Generated prediction outputs are written under:

```text
backend/evaluation_prediction/results/
```

Dataset preview prediction cache may be stored under:

```text
backend/data/dataset_preview_cache/
```

## Environment

- `EVALUATION_PREDICTION_ASSETS_ROOT`: optional standalone sample asset root.
- `EVALUATION_PREDICTION_RESULTS_ROOT`: output root, defaults to `backend/evaluation_prediction/results`.
- `CHART_MODEL_PROFILE`: unified model profile; current default is `gemini`.
- `CHART_BASE_URL`, `CHART_MODEL_NAME`, `CHART_API_KEY`, `OPENAI_API_KEY`, `CHART_API_URLS`: model overrides.
- `CHART_REPEAT_TIMES`: repeat count per prompt/image setting.
- `CHART_BAR_AMPLIFIER_ROUNDS`: bar amplifier refinement rounds.

Model profiles are defined in:

```text
backend/evaluation_prediction/common/model_config.py
```

API keys should be supplied through ignored local secrets or environment variables, not committed source.
