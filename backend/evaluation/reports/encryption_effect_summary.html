加密效果评估结果

评估对象：line、v_bar、h_bar、scatter、bubble
数据来源：backend/evaluation/reports/current_json_metric_report.json

指标计算方式

轴线角度误差：用当前 CV 轴线检测结果，分别和理论水平 X 轴、垂直 Y 轴比较，单位是度。

tick 位置归一化 MAE：对真值 JSON 和当前识别 JSON 中同名 tick 做匹配，计算像素误差，再除以该轴真值像素跨度。

abs(pred_pixel - gt_pixel) / (max(gt_pixels) - min(gt_pixels))

tick 覆盖率：当前识别 JSON 中能和真值 tick 匹配上的比例。

matched_tick_count / gt_tick_count

坐标变换 Norm MSE：基于 tick-value 到 pixel 的映射，把数据点分别用真值 JSON 和当前识别 JSON 映射到像素坐标，再计算归一化平方误差均值。

坐标变换 Pixel RMSE：同上，但直接在像素空间计算 RMSE。

表格中含斜杠的单元格格式为 mean / median。`v_bar` 和 `h_bar` 的均值会被少数异常样本显著拉高，因此 median 更能反映大多数样本的实际水平。
