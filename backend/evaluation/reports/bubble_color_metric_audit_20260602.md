# Bubble 图例-颜色准确率审计

数据来源：`backend/evaluation/reports/cartesian_cleaned_full_metrics_20260601.json`

评估范围：100 个 bubble 样本，共 800 个对象颜色。

## 结论

当前报告中的 bubble 图例-颜色准确率 `68.12%` 确实被低估了。低估的主要原因不是标签识别错误，而是评估方法使用 RGB 欧氏距离将预测颜色匹配到 GT 原始不透明调色板；bubble 图中的气泡通常是半透明绘制，并且可能互相重叠，最终可见颜色会明显浅化或混色。

因此，对 bubble 图表，把可见颜色直接和 GT 原始不透明颜色做 RGB 最近色匹配是不合理的。

## 当前指标

当前 cleaned 报告中的 bubble 颜色统计为：

| 指标 | 数值 |
| --- | ---: |
| 颜色对象数 | 800 |
| RGB 最近调色板正确数 | 545 |
| RGB 最近调色板准确率 | 68.12% |

该结果复现无误，但口径不适合 bubble。

## 替代审计结果

在保持对象标签映射一致的前提下，分别使用不同颜色判定方式重算：

| 判定方式 | 正确数 / 总数 | 准确率 |
| --- | ---: | ---: |
| RGB 最近 GT 调色板 | 545 / 800 | 68.12% |
| HSV 色相最近 GT 调色板 | 708 / 800 | 88.50% |
| 同标签色相误差 <= 15° | 769 / 800 | 96.12% |
| 同标签色相误差 <= 25° | 789 / 800 | 98.62% |

推荐 bubble 的图例-颜色指标使用 `同标签色相误差 <= 15°`。当前主汇总报告 `cartesian_cleaned_metrics_summary_20260602.md` 已采用该 bubble-specific 指标。

## 典型样本：bubble_000

`bubble_000` 的 GT 是原始不透明颜色，例如：

| 标签 | GT 原始颜色 | 当前预测颜色 | RGB 最近 GT | 色相最近 GT |
| --- | --- | --- | --- | --- |
| RUS | `#e78ac3` | `#e7bde0` | RUS | RUS |
| TUR | `#8da0cb` | `#c7d2e5` | TUR | TUR |
| IDN | `#fc8d62` | `#f8a98f` | ZAF | IDN |
| FRA | `#fdbf6f` | `#f9d5a8` | ZAF | FRA |
| EGY | `#66c2a5` | `#a8e1d3` | TUR | EGY |
| BRA | `#33a02c` | `#90c996` | EGY | BRA |

这些 RGB 错误主要来自气泡半透明后的浅化效果。以 `IDN` 为例，预测色仍明显是橙色，但 RGB 最近色会误匹配到浅粉色 `ZAF`。

`DEU` 是更特殊的重叠样本：它的小气泡被 `BRA` 大气泡覆盖，实际可见颜色发生混色，因此即使用色相也不一定能恢复 GT 原始红色。

## 关于对象标签和颜色映射

部分 bubble 样本中，`data_points` 的对象名是 `Z1..Z8`，而 `series_color` 的键是国家名或辅助标签。此时颜色在图中的实际对应关系来自插入顺序，例如 `data_points` 第 1 个对象使用 `series_color` 第 1 个颜色。这种位置 fallback 在这些样本中是合理的。

因此，本次低估并不是因为对象标签缺失。cleaned 报告里 bubble 的标签名准确率为 `100.00%`，也说明对象名提取本身没有问题。

## 建议

后续直角系全量报告中：

- bar/line/scatter 可以继续使用 RGB 最近 GT 调色板作为颜色指标。
- bubble 应单独使用 `bubble_hue_tolerance_accuracy`，当前主汇总已采用 `<= 15°` 结果。
- 推荐阈值：`HSV hue distance <= 15°`。
- 对严重重叠导致的可见混色样本，可额外标记为 `occluded/mixed-color`，不要简单视作颜色识别失败。
